# CX Interview Lab

한 질문씩 직접 답변하는 한국어 면접 학습 앱입니다. 정답을 외우는 대신 자신의 경험을 말하고, 참고 답변과 비교하고, 자기 평가로 다음 연습을 준비합니다. 기업 관리·공통 질문 라이브러리·면접 복기도 함께 제공합니다.

HTML, CSS, Vanilla JavaScript만 사용하며 기본 로컬 모드는 npm·빌드·서버·로그인·유료 API가 필요하지 않습니다. 선택적 기기 동기화는 Firebase 익명 인증과 Firestore를 사용합니다. GitHub Pages에서 정적 파일로 작동합니다. 클라이언트 비밀키가 없습니다.

## 최신 화면으로 새로고침

화면 우측 상단의 원형 화살표 아이콘을 누르면 작성 중인 면접 답변을 먼저 저장한 뒤 홈페이지를 다시 불러옵니다. HTML·CSS·JavaScript에 새 요청 식별자를 붙여 브라우저의 이전 파일 캐시를 피합니다. 저장된 기업·질문·답변·이력은 유지되며 현재 세션 위치/진행률은 초기화됩니다. 저장 실패 시 새로고침하지 않고 안내하며, 저장하지 않은 질문 편집이 있으면 먼저 확인합니다. 기존 개인 자료를 서버의 초기 질문 데이터로 덮어쓰는 기능은 아닙니다.

## 오늘의 연습 시작하기

1. **기업 선택**에서 전체 공통 질문 / 로앤컴퍼니 / 쿠어 / 직접 등록한 기업을 고릅니다.
2. **질문 구성**에서 공통 + 회사 전용, 연결된 공통만, 회사 전용만 중 고릅니다.
3. **진행 순서**를 순서대로 또는 무작위로 선택합니다.
4. **학습 범위**를 전체 / 특정 카테고리 / 다시 연습 / 이전에 연습하지 않은 질문으로 좁힙니다. 질문·키워드·답변 검색도 함께 적용됩니다.
5. 목표 시간 30·60·90초를 선택하고 **연습 시작하기**를 누릅니다. 질문이 없으면 시작 버튼을 비활성화하고 안내합니다.

로앤컴퍼니의 기존 본 질문 26개·꼬리질문 42개와 원문 답변은 그대로 유지했습니다. 2026-10-26 추가 요청에서 중복 5개를 제외한 새 질문 22개를 더해 기본 목록은 총 48개입니다. 신규 항목은 회사 전용이며 기존 브라우저에도 한 번만 추가합니다. [추가·중복 제외 내역](./QUESTION_UPDATES.md)을 확인할 수 있습니다. 23개 문항은 공통 라이브러리, 3개는 로앤컴퍼니 전용입니다. 회사별 원문 답변과 꼬리질문은 로앤컴퍼니 연결에 보존합니다. 공통 기본 답변은 비워 두며 로앤컴퍼니 이름이 명시된 꼬리질문은 회사별 연결에서만 사용합니다. 쿠어는 공통 질문을 연결한 준비 공간으로 추가합니다. 회사별 실제 답변·지원 직무·공고는 사용자가 직접 작성하며 경력 사실을 만들어 넣지 않습니다. 이미 쿠어를 등록했다면 중복 생성하지 않습니다.

## 전체 질문 리스트

메뉴의 **전체 질문 리스트**를 누르면 선택한 기업의 모든 문항이 표시됩니다. 질문을 클릭하면 참고 답변·핵심 키워드·꼬리질문과 참고 답변을 펼치고 다시 접을 수 있습니다. 회사/공통/모든 기업 보기, 카테고리 필터와 질문·답변 검색을 지원합니다. 모든 기업 보기에서는 동일한 공통 문항도 회사별 답변을 각각 표시합니다.

- **질문·답변 수정 → 수정 저장**으로 목록에서 바로 편집합니다. 공통 문항의 질문 수정은 연결된 모든 기업에 반영되며, 참고 답변은 표시된 해당 기업 또는 공통 라이브러리에만 저장합니다. 기존 연습 이력과 꼬리질문은 삭제하지 않습니다.
- **새 질문 추가**에서 저장할 기업 또는 공통 라이브러리를 선택하고 질문·참고 답변을 입력합니다. 기업 선택 시 회사 전용 질문으로 저장하며, 공통 질문은 기존 질문 라이브러리에서 기업에 연결할 수 있습니다.
- 저장 실패 시 입력과 원본을 유지하고 안내합니다. 취소하면 수정/추가 내용을 저장하지 않습니다. 꼬리질문·키워드 등의 상세 편집은 기존 질문 라이브러리에서도 가능합니다.

## 한 문항씩 연습하기

- 상단에서 회사명, 본 질문 번호, 이번 세션 완료 수와 진행률을 확인합니다. 진행률은 이번 세션에서 답변 완료한 본 질문 수이며 평가 점수가 아닙니다.
- **이전 본 질문 / 다음 질문**으로 이동해도 입력한 답변이 유지됩니다. 다음으로 넘어가기만 하면 완료 기록을 생성하지 않습니다.
- 텍스트를 입력하면 타이머가 시작됩니다. 수동 시작·일시정지·시간 초기화와 목표 변경도 가능합니다. 목표 시간이 지나도 자동으로 종료하지 않습니다. 화면을 벗어나거나 다른 탭으로 전환하면 일시정지합니다.
- **답변 완료**를 누르면 실제 작성 답변과 완료 시각, 소요 시간을 이력에 추가합니다. 같은 답변의 완료 버튼을 반복해서 눌러 횟수를 늘릴 수 없습니다. 답변을 수정하면 새 완료 기록을 만들 수 있습니다.
- **잘 답변했어요 / 조금 아쉬워요 / 다시 연습할래요**로 자기 평가합니다. 실제 AI 분석·점수 기능은 없습니다.
- **이 질문의 이전 답변 기록**에서 과거 답변·시간·자기 평가를 확인합니다. 최근 연습일도 표시합니다. 본 질문과 각 꼬리질문의 이력은 별도입니다.
- **학습 종료** 또는 마지막 문항의 **학습 마무리**에서 이번 세션 완료/미완료 문항 수를 확인합니다. 세션 순서·진행률은 새로고침 시 초기화되지만 답변과 완료 이력은 남습니다.

무작위 모드는 한 세션의 질문 ID를 한 번씩만 섞어 출제합니다. 이전 질문으로 돌아가는 것은 허용하며 새 질문 중복 출제와 구분합니다. 세션 재시작 때는 같은 범위의 질문을 다시 섞습니다. 미연습 범위는 과거 완료 이력이 없는 질문을 뜻하며 단순히 초안을 입력한 질문은 포함됩니다. 수동 재연습 표시 또는 최근 자기 평가가 재연습인 질문은 약점 범위에 포함됩니다.

### 참고 답변과 꼬리질문

**참고 답변 보기**는 언제든 펼치고 다시 숨길 수 있습니다. 답변을 보더라도 자신의 입력은 유지됩니다. 질문을 이동하면 다시 숨기며, 참고 답변은 정답이 아닌 준비용 예시라고 표시합니다. **직접 수정하기**로 현재 기업 또는 공통 공간의 참고 답변을 저장할 수 있습니다. 회사별 답변 수정이 다른 기업의 답변을 바꾸지 않습니다.

본 질문 답변을 완료하면 **꼬리질문 보기**를 사용할 수 있습니다. 꼬리질문은 하나씩 표시하며 이전/다음 꼬리질문, 본 질문으로 돌아가기, 다음 본 질문으로 건너뛰기를 지원합니다. 꼬리질문별 입력·타이머·참고 답변·완료 이력·자기 평가는 별도입니다. 등록된 꼬리질문이 없으면 해당 버튼을 숨깁니다.

### 음성 기능

- 질문 읽기: 브라우저 SpeechSynthesis와 한국어 음성을 사용합니다.
- 음성 답변: Web Speech API를 제공하는 브라우저에서 한국어 인식. 확정된 문장만 기존 입력 **뒤에 추가**하며 중복 결과와 질문 이동 후 늦게 도착한 결과를 무시합니다. 인식 중 임시 문장은 안내 영역에 표시합니다.
- 브라우저·기기·한국어 음성 설치·마이크 권한에 따라 지원이 다릅니다. 미지원 시 마이크를 비활성화하고 텍스트 입력을 안내합니다. 권한 거부·네트워크·마이크·음성 미감지 오류도 안내합니다.
- GitHub Pages의 HTTPS 환경을 권장합니다. 브라우저의 외부 음성 처리 서비스가 사용될 수 있으므로 민감한 정보를 말하지 마세요. 앱이 별도 음성 API나 유료 서비스를 호출하지는 않습니다.

## 세 가지 초기화의 차이

| 기능 | 초기화하는 내용 | 보존하는 내용 |
| --- | --- | --- |
| 현재 답변 초기화 | 확인 후 현재 질문/꼬리질문의 작성 초안을 비우고 이번 완료 상태 해제 | 타이머, 원본 질문, 참고 답변, 이미 완료한 과거 답변 이력 |
| 세션 다시 시작 | 확인 후 질문 순서, 현재 위치, 이번 세션 진행률 | 작성 초안, 질문, 참고 답변, 모든 과거 기록 |
| 전체 데이터 삭제 | 설정에서 ‘전체 삭제’ 입력 확인 후 이 앱의 모든 준비 데이터와 테마 삭제 | 다른 앱/사이트의 저장 키 |

세션 재시작은 결과 화면 또는 **설정 및 데이터**에서 가능합니다. 전체 삭제는 일반 연습 화면에 없습니다. 전체 삭제에는 기업·공통/전용 질문·회사별 답변·작성 초안·연습 이력·복기·이전 v1 원본도 포함됩니다. 삭제 후 빈 상태를 저장하므로 초기 예시 기업이 자동으로 다시 생성되지 않습니다. 실행 전 백업을 권장합니다.

## 기업·질문·복기 관리

- **기업 관리**: 회사명·지원 직무·공고·지원 상태·면접 일정·메모 등록/수정. 지원 상태는 지원 예정 / 서류 지원 / 면접 예정 / 면접 완료 / 결과 대기 / 종료입니다. 일정은 입력한 현지 시각 그대로 표시하며 시간대 변환·알림 발송은 하지 않습니다.
- **보관 / 복원**: 선택 목록에서만 숨기고 모든 자료를 유지합니다.
- **기업 삭제**: 확인창에서 해당 기업 정보·전용 질문·공통 연결·회사별 답변·연습 이력·복기 삭제를 안내합니다. 공통 원본과 다른 기업 자료는 남습니다. 이전 v1 원본은 일반 기업 삭제로 지우지 않으며 전체 삭제에만 포함합니다.
- **질문 라이브러리**: 공통 문항과 회사 전용 문항 등록/수정/삭제. 공통 문항을 기업에 연결하고 그 회사만의 참고 답변·꼬리질문·키워드·중요도·재연습 표시를 따로 저장합니다.
- **공통 문항 편집**: 본 질문·카테고리는 연결된 기업들이 공유합니다. 기업별 저장 답변은 유지됩니다. 관리 화면의 문항/답변 편집은 관련 완료·자기 평가를 초기화하며 기본 답변 이력은 보존합니다. 꼬리질문 구성이 바뀌는 관리 편집은 해당 꼬리질문 기록을 초기화하므로 변경 전 백업하세요. 연습 화면에서 참고 답변만 수정하면 학습 이력은 유지합니다.
- **연결 해제**: 해당 기업의 연결·참고 답변·그 문항의 기록만 삭제합니다. 공통 질문 원본 삭제는 연결된 모든 기업의 해당 자료도 함께 삭제하므로 확인창을 읽어 주세요.
- **면접 복기**: 실제 질문, 당시 답변, 아쉬운 점, 개선 답변을 저장·수정·삭제합니다. 개선 답변을 회사 전용 또는 공통 연습 질문으로 등록할 수 있습니다. 복기를 삭제해도 이미 등록한 질문은 남습니다.

## 기록·보안·기존 데이터 호환

저장 키는 기존 `cx-interview-lab:v2`를 유지하고 이력 필드를 추가합니다. 기존 회사·문항·답변·초안을 자동으로 덮어쓰지 않습니다. 쿠어 준비 공간과 이력 필드만 추가하며 이 버전 반영 뒤에는 삭제한 쿠어를 매번 다시 생성하지 않습니다.

v1 기록이 있으면 먼저 **기존 기록 이전**을 안내합니다. 명시적으로 이전하면 로앤컴퍼니로 복사하며, v1 원본은 보존하고 새로 작성한 v2 기록을 우선합니다. **나중에**를 선택하면 현재 창에서 새 기록으로 진행하고 다음 접속 시 안내합니다.

기존 버전에는 누적 횟수·완료 날짜가 없었습니다. 이전에 완료된 마지막 답변은 이력 1건으로 보존하고 날짜는 **이전 버전 기록 · 날짜 없음**으로 표시합니다. 실제 과거 누적 횟수나 날짜를 추정하지 않습니다. 대시보드의 횟수는 **보존된 본 질문 답변 완료 기록 수**이며 세션 수나 AI 점수가 아닙니다. 꼬리질문 횟수는 각 문항 이력에서 별도 확인합니다.

- 저장 실패 시 화면에 표시하며 입력을 보존합니다. 관리 변경·삭제는 저장이 확인된 뒤 반영합니다. 저장 실패한 완료 시도는 이력/횟수에 추가하지 않습니다.
- 손상된 저장소와 다른 탭에서 변경된 데이터를 감지하면 덮어쓰지 않습니다. 답변을 복사·백업한 후 원인을 확인하세요. 여러 탭의 동시 편집을 피하는 것을 권장합니다.
- **데이터 백업**은 설정 또는 데스크톱 메뉴에서 JSON으로 내려받습니다. 저장 원본(v1/v2), 현재 데이터와 작성 중인 답변 사본이 포함됩니다. 자동 가져오기 UI는 없으므로 복구가 필요하면 백업을 바탕으로 개발자의 도움을 받을 수 있습니다.
- 모든 개인 입력은 현재 기기·브라우저·접속 주소의 localStorage에만 저장됩니다. 기본은 로컬 전용입니다. Firebase 동기화를 별도로 연결하면 승인한 기기끼리 v2 자료를 공유할 수 있습니다. 비공개 모드 종료·브라우저 데이터 삭제·저장 공간 부족 등에 대비해 백업하세요. 백업에 이름·경력·채용정보가 포함되므로 공개 저장소에 올리지 마세요.
- 사용자 질문·답변은 `textContent`와 입력 값으로 표시하여 HTML을 실행하지 않습니다.

## PC · 모바일 동기화

로그인 화면 없이 Firebase 익명 인증과 기기 연결 코드로 동기화하는 선택 기능을 추가했습니다. 실제 사용에는 Firebase 프로젝트의 익명 인증, Firestore 데이터베이스, 보안 규칙과 공개 웹 설정이 필요합니다. 설정과 검증 상태는 [FIREBASE_SETUP.md](./FIREBASE_SETUP.md)를 확인하세요. 기본 설정은 `null`이므로 기존 로컬 기능은 그대로 작동합니다. 클라우드 연결 중에는 전체 로컬 삭제를 막으며, 동기화를 중지한 뒤 삭제해도 클라우드 자료는 자동 삭제하지 않습니다.

## 파일 구성 및 확장

- `index.html`: 학습 시작, 한 문항 연습, 결과, 관리, 설정 화면.
- `styles.css`: 밝은/다크 테마 변수, 모바일 화면, 키보드 포커스.
- `questions.js`: 로앤컴퍼니 원문 데이터. 고유 ID `lawcompany-q01`~`lawcompany-q26` 유지.
- `store.js`: 기업/공통·전용 문항 모델, v1 이전, v2 호환, 검증·저장·전체 삭제.
- `app.js`: 세션 순서·진행률, 문항/꼬리질문 이동, 초안·완료 이력, 타이머, 음성, 참고 답변 편집, 테마.
- `manage.js`: 기존 기업·질문·복기 관리와 백업.
- `tests/helpers.cjs`, `tests/smoke.cjs`, `tests/management.cjs`: 개발자용 브라우저 테스트. 앱 실행에 필요하지 않습니다.

질문 기본 필드: `id`, `category`, `question`, `answer`, `followUps`, `keywords`. `followUps`는 `{question, answer}` 배열이며 새로 수동 등록하는 항목은 안정적인 `id`와 `source: 'manual'`도 저장합니다. 향후 생성형 기능은 `source`와 추가 생성 메타데이터를 구분해 저장할 수 있습니다. 현재 AI 분석·자동 질문 생성·외부 AI 연결은 구현하지 않았습니다. 답변 기록은 문항 및 꼬리질문별 `history`에 `{id, date, text, seconds, rating, source}`로 저장합니다.

개인 자료는 앱에서 편집하세요. `questions.js`는 새 저장소의 초기 데이터이며 이미 저장된 v2 개인 자료를 코드 업데이트로 교체하지 않습니다. 이번 로앤컴퍼니 추가분은 별도 배치 식별자로 관리해, 기존 개인 편집·연습 이력을 보존하며 없는 항목만 합칩니다. 같은 문항을 이미 직접 추가했다면 기존 항목을 우선하고, 적용 후 삭제한 항목이나 삭제한 기업을 임의로 복원하지 않습니다.

## 실행·GitHub Pages 배포

루트의 `index.html`과 상대경로의 CSS·JS를 함께 사용합니다. 앱 자체는 서버나 빌드 없이 작동하는 정적 파일입니다. 파일 직접 열기는 브라우저별 저장·음성 제약이 있어 Pages HTTPS를 권장합니다.

GitHub에 커밋·푸시 후 **Settings → Pages → Deploy from a branch → main → / (root) → Save**를 선택합니다. 배포 완료 후 **Visit site**로 접속합니다. npm 설치나 빌드는 필요 없습니다.

## 개발자 검증

Node.js·Playwright·Chromium이 있는 개발 환경에서만 아래 명령을 사용합니다. 앱 사용자에게 설치를 요구하지 않습니다.

```sh
node --check store.js
node --check app.js
node --check manage.js
node tests/smoke.cjs
node tests/management.cjs
node tests/catalog.cjs
node tests/content-update.cjs
```

Chromium은 기본 `/usr/bin/chromium`이며 `CHROMIUM_PATH`로 변경할 수 있습니다. 공용 Playwright 도구 환경에서는 필요에 따라 `NODE_PATH`를 지정합니다. 테스트는 임시 HTTP 서버와 격리된 브라우저를 사용하고 종료 후 닫습니다.

검증 항목은 순차/무작위 출제, 전체 원문 표시, 범위 필터, 양방향 이동과 저장, 참고 답변 토글/편집, 초기화 구분, 타이머, 실제 완료 이력, 음성 누적·중복·오류, 회사별 분리, 기업/질문/복기 CRUD, v1/v2 호환, 저장·삭제 실패, 다중 탭 충돌, 백업, 전체 삭제, 모바일/다크 테마입니다. 실제 마이크 인식 품질·한국어 음성 재생은 지원 기기에서 별도 확인해야 합니다. 환경의 브라우저 정책으로 `file://` 자동 검증은 제한될 수 있습니다.
